# Lessons from the approver
The editor reads this before every post. Written automatically from rejections; newest last.

- [CELEBRITY COLLECTION] Use a photo only if it shows the exact reference named in the post; replace any photo of a different model.
- [CELEBRITY COLLECTION] Before researching, replace any [Name] placeholder with a real person who has an editorial profile in Hodinkee, GQ, WSJ, Esquire or Monochrome.
- [CELEBRITY COLLECTION] Source celebrity watch lists from editorial outlets first; use blogs and retailer write-ups only to cross-check a list an editorial source already names.
- [LISTICLE] Items in a listicle must be different models; never two references or colorways of one watch.
- [LISTICLE] Name each draft folder and title after its real format; a price listicle must not carry another format's label.
- [LISTICLE] Make the headline's number match the count of item slides, and check it after any add or cut.
- [LISTICLE] Use only prices dated within the past 12 months; drop any item whose price date is older.
- [LISTICLE] Before counting an item's photo as usable, confirm the file opens as a real image, not an HTML error page or a missing download.
- [LISTICLE] Pre-qualify a spare pool of dated, distinct, full-watch items above the recipe minimum, so rejected items can be swapped before drafting.
- [LISTICLE] Before drafting, confirm the chosen niche has the recipe's minimum of distinct, dated, full-watch items; if it falls short, switch niche or format, never pad.
- [LISTICLE] Check the item pool for the niche first; if it cannot reach the recipe minimum, pick a different format that the verified library can fill.
- [WOULD YOU RATHER] If a price source returns an error such as 429 or 404, mark that price unverified and swap in a candidate whose source opens.
- [WOULD YOU RATHER] Confirm a library entry's reference number on a fetched page; if no page shows that reference, drop the entry rather than keep its price.
- [WOULD YOU RATHER] Slide copy must match the carousel text exactly and fit one or two lines; comparison columns use model names only, so both columns align.
- [WOULD YOU RATHER] Only pair watches both buyable now; if one is list-price only, state 'list price only' on the slide, not just in the caption.
- [WOULD YOU RATHER] Pair prices only if they are within about 10% of each other; otherwise swap in a candidate inside the band before drafting.
- [WOULD YOU RATHER] After any swap or edit, re-run the validate check and do not mark the draft complete until it passes.
- [WOULD YOU RATHER] Include a spec (water resistance, bezel colour, complications) on a slide only if a verified claim or opened brand page states it; otherwise leave it off.
- [WOULD YOU RATHER] Leave out dates and other facts already in the slide footer, and keep option copy short enough that both columns stay on one line.
- [WOULD YOU RATHER] Generate each slide's rendered text directly from carousel.json, never retype it, so the render and the carousel copy cannot drift apart.
