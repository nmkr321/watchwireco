# Lessons from the approver
The editor reads this before every post. Written automatically from rejections; newest last.

- [NEW RELEASES] Match every slide's photo to the feature its text names (dial, bezel, wrist); view each image before assigning it.
- [NEW RELEASES] Keep source names out of slide body text; put each source beside its claim in the caption.
- [CELEBRITY] Make the cover the strongest permitted person photo with the watch in the circle; use a different portrait on later slides.
- [CELEBRITY] Print a year on a slide only if the source text or article date states it; otherwise leave the year out.
- [WATCH EXPLAINED] Before assigning any slide photo, view it. If it shows a grey 'coming soon' card, is blank, or failed to load, pick another permitted official image.
- [WATCH EXPLAINED] Any watch shown in a slide photo must be named with its exact brand and model in that slide or the caption, and must match the recipe's watch.
- [TOP 5 THIS WEEK] Answer each cover question or claim on a later slide with a specific figure; no slide may restate the previous one.
- [TOP 5 THIS WEEK] Name the exact metric the source gives (export value, sales, shipments); headlines must not imply cause or a metric the source omits.
- [CELEBRITY] Spotted-wearing slides need a photo showing the named watch clearly; if the wrist is too small, use a tighter crop or add a marker.
- [CELEBRITY] Compare watch variants with figures: state each price, or 'Price on request' if missing; avoid vague words like 'much less'.
- [WOULD YOU RATHER] Describe each watch's bezel, complication or function only as its named model has it. A GMT bezel tracks a second time zone, not a dive timer.
- [WOULD YOU RATHER] Captions describe each watch with its model's specific features (bezel type, case material, colour), never generic wording.
- [CELEBRITY COLLECTION] If an outlet returns 403 or is paywalled, use the next readable source naming the watch; one readable source is enough.
- [CELEBRITY COLLECTION] If sources disagree on a model reference, use the reference from the most recent readable source and show its price.
- [CELEBRITY COLLECTION] Copy each person photo's credit line exactly as photo.js or permissions.json gives it; never paraphrase it.
- [CELEBRITY COLLECTION] Before submitting, check every slide claim against its source text and rewrite any claim the source does not state.
- [STORY BEHIND] If sources disagree on a date or invention year, write the decade or range they share (e.g. "the 1970s"), or use the most recent readable source's date.
- [STORY BEHIND] Give a date or patent year only when one readable source states it; cite it beside the claim in the caption.
- [STORY BEHIND] Every slide of a photo-led format needs its own permitted, credited image; never reuse one within a carousel.
- [STORY BEHIND] Replace vague timing words like 'later' or 'recently' with the decade or year a readable source gives.
