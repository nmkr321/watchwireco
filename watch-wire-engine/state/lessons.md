# Lessons from the approver
The editor reads this before every post. Written automatically from rejections; newest last.

- [WOULD YOU RATHER] Generate each slide's rendered text directly from carousel.json, never retype it, so the render and the carousel copy cannot drift apart.
- [CELEBRITY] Before drafting, check posted history for the same person and watch; skip any pick posted within the past 7 days.
- [CELEBRITY] Put the named watch in a gold-circle inset on the cover, and show every watch the slides name.
- [CELEBRITY] Use only sightings dated within the past 90 days, and confirm them with a second outlet or a dated photo; otherwise pick a different celebrity.
- [CELEBRITY] State a watch's dial colour or other visual detail on a slide only when research confirms it; otherwise leave the detail off.
- [CELEBRITY] When sources conflict on a watch's case size or reference, omit those specs and pick a sighting where the sources agree.
- [CELEBRITY] If the first candidate fails verification, search for another celebrity sighting instead of ending the run without a post.
- [CELEBRITY] Use a celebrity photo only when the named watch is visibly on the wrist; event or branded-backdrop photos don't qualify.
- [CELEBRITY] Before insetting a watch image, match its dial, bezel and bracelet to the exact reference; if none matches, omit the inset.
- [CELEBRITY] Give every slide a specific hook headline drawn from verified facts; never use a generic label like 'Retail price in US dollars'.
- [CELEBRITY] Before rendering, keep labels clear of figures, centre each slide's content block vertically, and re-render until spacing looks balanced.
- [CELEBRITY] If standard searches return only old or undated pages, run an extended search before rejecting that candidate.
- [CELEBRITY] Accept a sighting only from a source that prints its publication date; drop undated pages from the verification count.
- [CELEBRITY] Verify the watch as its own claim: a second source must name the same watch on the same person, not just the celebrity.
- [LISTICLE] Confirm every watch reference number against its source page before drafting; use the exact reference shown there, or drop the watch.
- [LISTICLE] Use only clean cut-out product photos on plain black; if a photo shows any shadow, smudge or background remnant, choose another photo.
- [LISTICLE] Plan at least 8 slides before drafting; if candidates fall short, add watches or switch to a shorter format rather than rendering fewer.
- [LISTICLE] If a source page fails (e.g. HTTP 429), verify that watch through a second source or drop it; never keep unverified facts.
- [LISTICLE] Before counting a watch toward the slide minimum, confirm it has a clean cut-out photo and a verified price in the target band; drop non-qualifiers first.
- [LISTICLE] Research at least 12 candidate watches before choosing, so at least 8 survive the photo, price-band and reference checks.
