# Lessons from the approver
The editor reads this before every post. Written automatically from rejections; newest last.

- [WATCH EXPLAINED] Name in cover tag and sub-line only watches visibly pictured on the cover; mention other models in later slides that show their photo.
- [CELEBRITY] Take prices only from the brand or an official retailer; cite independent trackers only as resale estimates, never as retail price.
- [CELEBRITY] Include a slide showing the celebrity wearing the featured watch, and keep the inset and all text off his face.
- [CELEBRITY] Before approving a portrait cover, check the rendered image: the watch inset must sit in a corner, fully off the face.
- [CELEBRITY] When a review flags a fix not yet applied, change the layout itself; never re-render the same template position.
- [CELEBRITY] Every slide that names a person or watch must show its permitted photo; never place that slide as text on plain black.
- [CELEBRITY] Slide bodies must state sourced facts or specifications only; replace opinion claims like 'our take' with a cited spec.
- [CELEBRITY] Use only sightings and prices dated within the last 12 months; for any older source, put its month and year in the body and caption.
- [CELEBRITY] Never use 'wears', 'spotted' or 'now' for a sighting unless a month and year sit in the same sentence.
- [CELEBRITY] Before choosing a subject, confirm both a permitted watch photo and a brand or retailer price exist; if either is missing, drop that candidate and try the next.
- [CELEBRITY] If a brand site blocks access (403) and no permitted source gives its price, switch to a candidate with accessible sources; never guess a price.
- [CELEBRITY] Use only a permitted photo of the exact reference and case size named in the post; drop any candidate lacking one.
- [CELEBRITY] Take the price from the brand page for the exact reference named; if only a search snippet exists, use another candidate.
- [EVENT SPOTTED] Name a person only if a permitted full-size photo of them is in state/permissions.json; otherwise drop that person and pick another.
- [EVENT SPOTTED] Reject any image too small for the slide template, including watermarked or agency thumbnails; find a larger credited original instead.
- [EVENT SPOTTED] Before writing, confirm a source dated in the event's year names the watch on a named person; if none exists, switch to another event or subject.
- [EVENT SPOTTED] Pick the named person from state/permissions.json first, then search for that person's sightings; never search for sightings of people with no permitted photo.
- [CELEBRITY] Pick watches whose exact reference is in the permitted library and published by the brand; never name a reference from a press article alone.
- [CELEBRITY] Name the full model and reference in the post, never a bare brand name, and make sure a permitted photo shows that same reference.
- [CELEBRITY] If no candidate passes every check, draw new candidates from the permitted library until one does; never publish a failed one.
